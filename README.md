# Exhibitor Directory Flipbook

Interactive HTML5 flipbook demo for the exhibitor directory.

## Demo
Open `index.html` through a web server / GitHub Pages.

## Replace the PDF later
In `index.html`, change:

```js
const PDF_URL = 'dummy-directory.pdf';
```

to the final generated directory PDF URL.

The viewer uses PDF.js for rendering and PageFlip for the page-turn animation.
